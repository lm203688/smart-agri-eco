§ 01

核心能力

Core Capabilities

十个模块对应平台全部可调用能力：四项流水线 Agent、三项反应式技能、土壤与物候专项、环境配置调度、本地检索、跨会话记忆、数据飞轮与质量基线。

地块与场景

Plot & scene parameters
四 Agent 协同：ClimateAgent → CropAgent → GrowthAgent → EcoAgent。工作项自动流转并写入长期记忆。
◇填写左侧参数后点击「生成方案」
四 Agent 闭环将在约 1 秒内返回完整方案与可信证书

症状与诊断

Symptom description → evidence-gated diagnosis
证据门控（零误报策略）：证据不足时明确返回「未确认」，不给出确定性诊断。 附三阶段推理链：预测 → 解释 → 处置映射。
◇描述症状后点击「诊断」

阶段化施肥

Crop-family NPK profile → staged fertilization plan
按科属推断氮磷钾侧重，输出播种→苗期→生长→采收四阶段配方。
◇填写作物与阶段后点击「生成方案」

霜冻锚定播期

Frost-anchored planting windows (WOFOST GDD)
由月均温推导无霜期与 GDD 积温，给出各作物最早 / 最晚安全播种日。
月均温为近似气候常态值，仅作演示输入；生产环境应由调用方传入实测序列。

或用真实经纬度自动获取气候

NASA POWER（公有领域）实时拉取 · 失败回退 Open-Meteo（CC BY 4.0）
后端按经纬度实时拉取 12 个月均温（带来源与取数时间标注），无需手填。
首次拉取约 2–6 秒；结果写入本地缓存，二次调用免联网。
◇选择城市与作物后点击「推导播期窗口」

土壤画像

SoilGrids online first → offline zone fallback
在线不可达时自动降级为分区均值画像，并标注数据来源为离线兜底。
中国坐标查询偶发慢响应，为防用户端挂死，超时保持严格。
◇填写坐标后点击「查询土壤」

条件锚定调度

Env Recipe → threshold & keyword anchors
不依赖固定时刻：锚点由配方阈值与异常处理文本推导，返回 ready / waiting 动作集。 字段名必须与锚点 field 精确匹配（temp_c / humidity_pct / ph / water_ml）——单位错一个量级就会误触发。
◇填写作物、分区与观测后点击「评估动作」

知识底座浏览

110 作物 · 6 分区 · 23 病虫害 · 110 配方
⚠️ 数据性质：本库为 AI 依据公开农艺通识 + 权威资料（GAEZ/WorldClim/USDA/FAO/IPNI/WOFOST）编撰的冷启动种子，非经自动化管道从外部源实时抓取入库。适配分（adapt_score）现已对 107/110 作物用生态位包络反推实证校准：以 GBIF 真实物种分布点 + NASA POWER / Open-Meteo 真实气候反推气候适宜包络，对照 6 分区基线得出（calibration_method=niche_envelope），非手编近似；另有 3/110（樱桃萝卜/豆芽/微绿菜，属栽培品种或加工形态，GBIF 无物种分布点）仍 calibrated:false。注意：此校准为「0 用户下唯一能实证」的气候生态位反推，仍不同于「真实种植结果回流校准」——后者需用户反馈，数据飞轮目前 0 条记录。数值仅供方案生成参考，正式商用前须以权威源逐条核验。
点击左侧条目查看完整画像。作物可按分区筛选、按名称/风险检索。
◇选择上方分类开始浏览知识底座

本地三层检索

FTS5 + CJK bigram + hash vector, zero network
索引为派生产物（sqlite3 FTS5），不触碰源 JSON；中文按连续 CJK 2-gram 切分以保证查询侧与文档侧一致。
◇输入查询后点击「检索」

跨会话记忆与工作项

Cross-session recall + append-only work item audit
记忆六层加权（主体 / 技能 / 标签 / 查询 / 时效 / 向量）； 工作项为 7 态 5 模式声明式状态机，非法转移被拒绝且不改变状态，审计只存 16 位摘要。
◇两次操作：记忆召回、工作项状态机全链路

数据回流

Real outcome feedback → score calibration
诚实基线：平台当前真实用户反馈为 0 条，此表单是回流闭环的入口。 合成测试数据带标记并被 CI 门禁拦截，不会冒充真实数据。
◇提交一次真实种植结果，参与适配度校准

BP 文本初筛

Business plan → completeness & risk triage
完备性 + 风险初筛：三档结论（通过 / 需深挖 / 淘汰）+ 六评分卡 + 五闸一票否决 + 11 区块报告。
不构成投资决策建议——本地核验库是演示数据，仅做字段完备度与红旗检测。
文件在浏览器内读为 base64 上传，服务端解析（Word 零依赖；PDF/Excel 缺依赖时自动降级）。每次初筛（文本或文件）自动归档到下方「我的评估」。
◇粘贴 BP 文本后点击「初筛」，或上传文件
九层管线：解析 → 抽取 → 归一化 → 合理性校验 → 分类 → 核验 → 缺口 → 评分 → 报告
