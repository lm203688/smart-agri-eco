# engineering_regression · L0 工程回归基准层

> **层级定义（对齐 `项目全面提升报告_2026-10-26.md` §四 P0-1 三层分类）**

| 层 | 名称 | 数据源 | 允许用途 |
|---|---|---|---|
| **L0** | **engineering_regression** | 被测模型固定快照（±30% 容差） | 验证"不变"，防回归 |
| L1 | agronomic_reference | 独立文献/专家标注/机理模型 | 证明接近真实农艺 |
| L2 | field_holdout | 按批次/站点/时间隔离 | 评估泛化能力 |

## 本目录是什么

**L0 工程回归基准**：验证被测模型（ForecastAgent + 机理内核）相对**自身固定快照**的行为不变。它是**回归防线**，不是农艺真值。

## 用例宿主（重要）

当前 89 个基准用例**物理位于** `../agri_recipe_bench/cases/`（69 正例）+ `../agri_recipe_bench/cases/neg/`（20 负例），由 `../agri_recipe_bench/run_bench.py::load_cases()` 加载。

**本目录不复制用例文件**——因为：

1. **证据等级不因路径而变**：用例的 `expected` 是模型自身输出 ±30% 填充的自回归基准（见用例 `provenance` 字段），挪到任何目录都是 L0。
2. **避免破坏 CI 硬门禁**：`run_bench.py --strict` 依赖 `cases/` 目录结构与 89/89 计数；物理迁移会触及 `load_cases()` 的 `CASES_DIR` 常量与 CI 期望值，属高风险结构性变更，需独立会话执行。

因此本目录作为 **L0 语义声明 + 指向宿主**，供报告层区分引用。

## 诚实边界（禁止合并宣传）

- 这 89 个用例**全部是 L0**：无一个用例带独立农艺真值（无 `source_truth` / `ground_truth` / `reference` 字段，`expected` 为模型自回归基准）。
- **不得**以"89/89 通过"进入"产量准确率"宣传。
- 正确表述：**"L0 工程回归通过（89/89）——验证行为不变，非验证农艺准确。"**

## 与 L1/L2 的关系

- L1（`../agronomic_reference/`）：需独立文献/专家标注/WOFOST 机理真值——当前 **0 用例**（需外部数据）。
- L2（`../field_holdout/`）：需真实种植批次按站点/时间隔离——当前 **0 用例**（需 P1 真实批次）。
