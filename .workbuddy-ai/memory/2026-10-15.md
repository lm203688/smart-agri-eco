## 方案核心主张
- **愿景定位**：不做第五个农业决策者，做**第一个验证者** ——「农业决策的验证层 + 可执行数字孪生」（Verifiable Agricultural Decision Layer）
- 依据：大模型阵营（神农世界模型/司农 LLM/OneGenome-Rice/四大农业大模型 2026-05）不满足「本地可离线 + 可解释可复算 + 有不确定性保证 + 小样本校准」；云 MCP 不满足离线；机理模型不满足 Agent 接口与微场景。**四阵营盲区交集即本项目位置**
- **六大支柱**：
  1. **AgriWorld-Lite** — 零依赖**可微分**（手工解析梯度）微场景数字孪生：光截获 Beer-Lambert + 同化 + 分配 + 呼吸 + Penman-Monteith 蒸腾 + 根区水氮平衡；反事实轨迹产品化（把 bench 的 17 个 counterfactual 用例从评测变能力）
  2. **Hybrid Calibration** — 机理先验 + 残差模型 + 条件保形；**3-5 条实测即可校准**；**主动实验设计**（信息增益推荐，破解 feedback 0 的鸡生蛋）
  3. **VDC 可验证决策契约** — 前提/承诺/违约判定/归因/可复算；「不能验证的建议永远只能免费」
  4. **联邦校准协议** — 只传校准增量不传原始数据；零依赖本地优先 → 独占微场景数据（大模型永远拿不到）
  5. **Verify-as-a-Service** — `agri_verify_recommendation`（第 22 工具）：物理约束冲突/物候冲突/环境-品种冲突三类检出
  6. **协议栈占位** — MCP Tasks（生长季长任务）+ A2A 验证委托 + AG-UI + UCP/AP2 计费

- **三阶段路线**：N+1 科学地基（0-3月，7 项，科学性 4.5→6.5-7.0）→ N+2 信任产品（3-6月，VDC/主动实验/联邦/外回路）→ N+3 生态位确立（6-12月，验证服务/联邦公测/计费/论文）
