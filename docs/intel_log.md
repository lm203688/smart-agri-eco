# 智慧农业生态 · 情报日志（intel_log）

> 本文件为**手动 / 按需**维护的情报日志模板（当前**未接入自动化**——本项目仅保留一个每日单口巡检闭环）。
> 记录农业 AI / 垂直农业 / 智慧农业 / 农业 Agent 的最新进展、竞品动态与可借鉴改进点。
> 闭环定位：情报（发现差距）→ 数据校准（执行）→ 评审自评（度量）。其中仅「每日巡检」为自动化，情报收集按需手工触发。

---

## 格式约定

每次运行追加一个 `## YYYY-MM-DD` 分段，包含：

- **检索关键词**：本次覆盖的情报主题
- **可借鉴改进点**（≤5 条）：每条含 `来源` / `对本项目价值` / `建议落地动作(P0/P1)`
- **自动 Skill 生成**：若发现新能力点，调用 `python -m engine.skill_factory` 并记录
- **数据缺口**：若发现数据缺口，写入 `docs/project_evaluation.md` 的「迭代待办」
