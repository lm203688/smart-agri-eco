## 1. 市场对标

| 竞品 | 定价 | 覆盖 | 我们的差异化 |
|---|---|---|---|
| **FieldMCP** | $29/org/month | 150+ tools / 12 领域 | 方法深度（107 双源校准 / 4 血缘 / 偏差校正）vs 数量广度 |
| **Leaf Agriculture MCP** | 未公开（企业合同） | 数据聚合（John Deere/CNH 等） | 知识配方 vs 数据入口（互补） |
| **agstack pestmodels** | 免费（开源） | 13 models / 54 threats | 开源互补而非竞争 |
| **mcp-agriculture (Rust)** | 免费（开源） | 35 tools | 数量竞争，我们不追 |

**结论**：$29/org/month 是农业 MCP 商业化的**市场锚点**。我们不追数量（FieldMCP 150+ 是数量竞争），护城河是**方法深度**——107 双源校准、4 血缘追溯、气候多源偏差校正。

---

## 2. 商业化边界（战略约束）

**我们要做的事**：
- ✅ **只做 MCP 分发**：MCP server + Python SDK + 数据 API 三入口
- ✅ **被调用次数衡量价值**：不建 SaaS、不做 C 端、不做配方授权
- ✅ **免费换数据**：使用即贡献（feedback_log / execution_log / image_consent）

**我们不做的事**：
- ❌ 不建 C 端 App（违背壁垒④）
- ❌ 不做 SaaS 托管（违背壁垒③ Agent-native）
- ❌ 不单独授权配方（配方是免费知识底座）
- ❌ 不承诺 SLA（v0.9-beta 邀请制阶段）

## 3. 三档定价提案

### 档 1：Free Tier（社区版）

| 维度 | 内容 |
|---|---|
| 定价 | $0 / 月 |
| MCP 工具 | 全部 14 个（含 `agri_list_ecosystem`） |
| 调用频次 | 1000 次/月 |
| 数据范围 | 110 配方 / 107 校准 / 8 分区 |
| 血缘追溯 | 4/4 完整 |
| 商业化边界 | 需开源回馈（提交 feedback_log / execution_log） |
| 目标客户 | 个人开发者、学术研究者、早期创业团队 |

**定位**：拉用户、收真实数据（壁垒 ④ 回流校准）。

### 档 2：Pro Tier（专业版）

| 维度 | 内容 |
|---|---|
| 定价 | **$49 / org / 月**（对标 FieldMCP $29 + 40% 溢价） |
| MCP 工具 | 全部 14 个 + 高优先级工单响应（48h） |
| 调用频次 | 100,000 次/月 |
| 数据范围 | 全部（含 hot_arid/highland 新分区） |
| 血缘追溯 | 4/4 + 数据来源审计 |
| 商业授权 | 可商用（内部使用） |
| 目标客户 | 中型农业企业、精准农业项目、AgTech 初创公司 |

**溢价理由**：
- 偏差校正（climate_reconcile）是 FieldMCP 没有的方法论能力
- 血缘追溯是"知识配方"的核心差异化
- 4 层 harness 门禁保证数据可信度

### 档 3：Enterprise Tier（企业版）

| 维度 | 内容 |
|---|---|
| 定价 | **定制报价**（$200-2000/org/月） |
| MCP 工具 | 全部 + 专属 API 限流提升 |
| 调用频次 | 无限（Fair Use 政策） |
| 数据范围 | 全部 + 定制分区建模 |
| 血缘追溯 | 4/4 + 自定义追溯规则 |
| 商业授权 | 可商用 + 白标授权 |
| 技术支持 | 专属 CSM + 4h 响应 SLA |
| 定制服务 | 分区建模（如中东/东南亚专属）、配方生成、数据导入 |
| 目标客户 | 大型农业集团、政府项目、跨国农业基金 |

**溢价理由**：
- 定制分区建模是壁垒 ② 核心
- 白标授权满足大型客户品牌需求
- 专属 CSM 满足合规审计要求

## 4. 定价锚点分析

| 竞品 | 定价 | 我们的对标逻辑 |
|---|---|---|
| **FieldMCP** $29/org/month | Pro $49 (+40% 溢价) | 方法深度 vs 数量广度；4 血缘 + 偏差校正差异化 |
| **Leaf Agriculture** 企业合同 | Enterprise 定制报价 | 数据入口 vs 知识配方（互补而非替代） |
| **agstack pestmodels** 免费开源 | 作为生态对接而非竞品 | 我们不重复造轮子 |

**为什么 Pro 定 $49 而不是 $29**：
- $29 是市场锚点，直接对齐会被视为"便宜版 FieldMCP"
- $49 溢价 40% 是**明确的方法深度差异化**信号
- 早期用户接受度高（Pro 用户是 20-50 人的精准农业项目，$49 是小成本）

## 5. 转化漏斗（目标）

```
Free (社区版)
  ↓ 数据回流 + 用户口碑
Pro (专业版, $49)
  ↓ 定制需求 + 品牌授权
Enterprise (企业版, 定制)
```

**关键指标**：
- Free → Pro 转化率目标：5%（对标 SaaS 行业 3-5%）
- Pro → Enterprise 转化率目标：10%
- Free 用户数目标（v1.0 后 6 个月）：500+
- Pro 用户数目标：30+
- Enterprise 用户数目标：3-5

## 7. 定价风险与对策

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| **Marketplace 竞争** | 中 | 中 | 我们走方法深度路线，不追数量；差异化护城河稳固 |

| **竞品降价** | 中 | 中 | 我们 40% 溢价有方法深度支撑，降价空间充足 |
