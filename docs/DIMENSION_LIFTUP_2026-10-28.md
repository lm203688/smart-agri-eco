## 2. 三视角交叉评估

### 2.1 领域专家（农学）视角 —— "机理可信，但数据可信度是命门"

- **认可**：WOFOST 机理内核 + 239 作物 + Köppen 8 分区 + 152 配方设定点，属"可推演的物理 AI"（区别于感知/认知 AI），方向正确。
- **担忧**：配方 `data_quality=modeled`（模型推算，非田间试验）、`sources[].url` 仍有空值、WOFOST 仅 7 作物权威参数（其余启发式）。**专业用户"一看即知"是推算值，信任会打折。**
- **机会**：农民日报明确"田间测试-反馈迭代闭环"是普惠落地关键——我们缺的是**真实回流**（G2 目标：feedback ≥30 / outcome ≥20 / 图像 ≥50），这正是 G1 之后的第一优先级。

### 2.2 AI 项目专家视角 —— "协议已前沿，分发未执行"

- **认可**：MCP 2026-07-28 无状态对齐 + A2A 1.0 Card + JWS + 零依赖 + 保形预测，是 12000+ server 中的稀缺组合（多数只做"工具数量"竞争）。
- **担忧**：**0 外部调用**。协议再前沿，无调用即无价值。N10 明确"不堆工具数量"——FieldMCP 150+/神农 MCP 开放后，数量竞争已无意义，**质量、可信、可复现才是壁垒**。
- **机会**：MCP 生态 2026 出现"安全危机"（仅 8.5% server 实现 OAuth 2.1、53% 硬编码凭据、492 server 零认证暴露公网）——**我们凭据不入库（P0-7 已清零硬编码密钥）**，天然具备"可审计 + 安全"的差异化卖点。

### 2.3 真实用户视角（三类） —— "能跑通但还不够闭环"

| 用户 | 痛点 | 当前满足度 |
|---|---|---|
| 家庭/阳台种植 | "种什么、怎么浇、叶子黄了怎么办" | 中高（有推荐/诊断/配方，图片入口待补） |
| 中小农场/温室 | "投入多少、能赚多少、天气变了怎么办" | **中高**（**economics + postharvest 已补**，实时天气待补） |
| 农业 Agent 开发者 | "接入多快、文档在哪、出错怎么办" | **高**（QUICKSTART + TOOLS_REFERENCE 三段式 + examples） |

> 10-22 报告的最大用户痛点"无 quickstart / 工具描述过简 / 无经济学"——**本轮已全部解决**。用户侧短板从"进不来"转为"闭环弱"（实时天气/图片诊断/多轮）。

## 3. 前沿趋势对齐（2026-10 一手事实，来源可核）

### 3.1 MCP 2026-07-28：无状态核心（已对齐 ✅）
- 无状态架构：移除握手 + Mcp-Session-Id，请求自包含 → 可 serverless/边缘/负载均衡部署。
- **Tasks 扩展**（SEP-2663，poll-based tasks/get + tasks/update）——长时运行任务；MCP Apps 官方化；Roots/Sampling/Logging 弃用（SEP-2577）。
- 生态数据：**97M 月 SDK 下载**、12000+ servers、28% Fortune 500、78% 企业 AI 团队用 MCP 于生产。
- **我们的位置**：`PROTOCOL_VERSION="2026-07-28"`，无状态已落地 → **第一梯队**。唯一可再进一步的是 **Tasks 扩展**（当前 batch 工具是同步返回，长时批次任务可考虑 Tasks，但属 P1 后）。

### 3.2 A2A 1.0 GA（2026-04）：Agent 互联网（已对齐 ✅）
- Google/AWS/Microsoft/Salesforce/SAP/ServiceNow + 150+ 组织；Microsoft Agent Framework 1.0（Semantic Kernel+AutoGen 合并）原生 MCP+A2A。
- **我们的位置**：A2A Card v1.0 + 30 skills + JWS → 已对齐。

### 3.3 农业"物理 AI"：SNWM / 神农 4.0 开放 MCP（重要生态变化 ⚠️）
- **神农 4.0（2026-07-11）**：开放 **API + MCP 服务**；1016 种病虫害识别（93%）；AgriTalk 10 方言；神农 Pro 长链思考；2026-09-16 肯尼亚专属智能体"神农 Zao"。
- **神农·农业世界模型 SNWM 1.0（2026-07-12）**：全球首个动作条件化、设施+大田双域验证的农业世界模型；番茄/生菜/黄瓜三作物跑通。
- **含义**：中国农大已把"大模型层"开放成 MCP 服务。**数量竞争彻底失效，我们不可能也不应该做大模型**（N9 边界）。我们的价值在**作为它的机理约束层与可审计配方层**。

### 3.4 具身智能农业：群体智能 + 数字孪生闭环（前沿主战场，P2 后）
- 农业机器人市场 2026 破 **1035 亿美元**；"农田-作业-机群"三级孪生 + 端-边-云分层协同 + 多智能体强化学习 + 地空跨域协同。
- **含义**：我们的 `agriworld_lite` 数字孪生 + `control_agent` 执行控制，正是"可推演物理 AI"的雏形。但**真实闭环需硬件/田间数据**（记忆已标 BLOCKED），属 P2 后。

## 5. 战略定位结论（本轮最重要）

> **我们不是"又一个农业大模型"，而是"大模型的机理约束器 + 可执行配方 + 可审计资产"——即农业 AI 三层协同体系中的"机理模型 + 专业小模型"层。**

- 行业已确认（农民日报 2026-09-30）：单纯堆资料无法根治大模型幻觉，**必须用机理模型作为底层知识约束**。
- 我们的 Env Recipe + WOFOST + 保形 + 因果，恰好是那个"约束层"。
- 对神农/SNWM 的定位：**不竞争，承接**——它们提供"理解与调度"，我们提供"科学约束与可复现执行"。这是 2026 年生态位的最优解。
