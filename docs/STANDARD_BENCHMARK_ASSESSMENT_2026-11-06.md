## 一、逐项对标结果

### 1. 可复现性硬门槛 —— ✅ 已达标（核心），⚠️ 需补 CI 固化

| 子项 | 现状 | 证据 | 结论 |

| 时钟可控 | ✅ `core/clock.py`：`SystemClock`/`FrozenClock`，替换原 62 处 `datetime.now()` + 51 处 `time.time()` | `FOUNDATION_AUDIT_2026-10-16.md` H2 修复记录 | 已达标 |
| 随机性可控 | ✅ 同上（随机性全部收敛到 seed 可控实例，不依赖全局 random） | 同上 | 已达标 |
| 环境锁定 | ⚠️ `requires-python=">=3.10"`，**无 requirements 锁文件**（零第三方依赖，运行时无需 pip install） | `pyproject.toml` 行10 + 行22 `dependencies=[]` | 依赖本身零，**但 Python 版本矩阵未在 CI 固化** |
| ±2σ 重跑 | ⚠️ 单测/Bench 可重跑但**无 ±2σ 统计门禁**（未做"多次运行统计稳定性"断言） | 单测 1029 全绿；Bench 89/89 稳定 | 可补充提升 |

**提升项 1-1（P1）**：新增 `scripts/check_reproducibility.py` —— 对核心预测（`agri_forecast`/`recommend_crops`/`match_zone`）跑 **N=10 次**，断言结果序列稳定（相同输入→相同输出，0 方差），并输出可复现性统计（均值/标准差/置信区间）。验收：脚本 CI 门禁通过 + 核心输出方差=0。
**价值**：把"可复现"从"设计原则"升级为"可执行门禁"（±2σ 精神的具体化），强化护城河叙事。
**成本**：约 0.5 天（一个脚本 + 复用现有 core.seed/core.clock）。

### 6. 能力基线 —— ⚠️ **不适用**（领域不同，如实标注）

- 本项目是**农业知识基座 / MCP 服务**，非 EEG/BCI 神经接口分类任务。官方基线（Constant 33.3% / EEGNet 32.6% / CTNet 35.0% / REVE 36.0%）对应的是**跨人迁移分类**任务，与本项目**无同类任务可比**。
- **诚实结论**：不适用，且**不虚构**对标数字。若未来涉足模型训练/分类，需另立基线；当前纯推理配置无需 chance 基线。
- **可借鉴点**（不是提升项，是启发）：官方基线"专业模型刚过 chance"说明**标准门槛可能很低，但可信提交需要真实能力**——本项目对应的启示是：**G1 外部调用（≥500/≥20）是"真实能力"的试金石**，比任何 self-benchmark 都更接近"标准门槛"精神。

## 三、结论（回传 Chief 摘要用）

**评估结论**：项目在**数据合规 / 提交约束 / IP 归属**三维度**已全达标**；**可复现性 / 评测标准化**设计层已达标但缺**可执行门禁**（2 个可操作提升项，合计约 0.7 天，均 P1/P2）；**能力基线维度不适用**（非同类任务，如实标注不虚构）。
